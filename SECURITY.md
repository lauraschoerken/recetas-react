# Security Policy

## Supported versions

Security fixes are applied to the current `develop` branch. Older commits and deployed versions may not receive separate fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or screenshots.

Use GitHub's private vulnerability reporting for this repository: open the **Security** tab, select **Advisories**, and choose **Report a vulnerability**. Include the affected version or commit, impact, reproduction steps, and a minimal proof of concept without real user data.

If the private reporting button is unavailable, open a public issue containing no technical or exploit details and ask the maintainer for a private contact channel.

Please allow the maintainer time to confirm the report and coordinate a fix before public disclosure.
